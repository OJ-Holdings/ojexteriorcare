## Deploying

The site deploys from `main` through Vercel (Oscar's Vercel account). Vercel only builds a commit if its Git author has access to the Vercel project. A commit authored by someone without access (for example a direct push from Jacob) shows "Deployment was blocked" and nothing goes live.

To ship such changes: open a pull request and have Oscar merge it with a merge commit (not squash), or have Oscar push a commit on top. A blocked deployment is not a code problem; the build itself passes.
